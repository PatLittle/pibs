# Errors / Erreur

## We couldn't find that Web page

**Error 404**

We're sorry you ended up here. Sometimes a page gets moved or deleted, but hopefully we can help you find what you're looking for. What next?

* Return to the [home page](/index-eng.aspx);
* Try a [search](https://www.canada.ca/en/school-public-service/search.html) to find what you need;
* [Contact us](/contact_us/index-eng.aspx) and we'll help you out.

## Nous ne pouvons trouver cette page Web

**Erreur 404**

Nous sommes désolés que vous ayez abouti ici. Il arrive parfois qu’une page ait été déplacée ou supprimée. Heureusement, nous pouvons vous aider à trouver ce que vous cherchez. Que faire?

* Retournez à la [page d'accueil](/index-fra.aspx);
* Effectuez une [recherche](https://www.canada.ca/fr/ecole-fonction-publique/rechercher.html).
* [Communiquez avec nous](/contact_us/index-fra.aspx) pour obtenir de l'aide.
